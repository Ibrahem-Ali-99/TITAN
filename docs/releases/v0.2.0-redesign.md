# TITAN v0.2.0 frontend redesign

Status: locally release-validated; publication is pending the authorized GitHub workflow.

Validated on 2026-11-26 from branch `feature/titan-v0.2.0-final-ui` against the
running local Compose platform. The redesign keeps the existing Next.js routes,
API proxy, authentication boundaries, RBAC behavior, and real-data contracts.

## Console scope

All eight dashboard routes render the persisted or published API contracts used by
the running local demonstration:

| Route | Screen | Live evidence |
| --- | --- | --- |
| `/` | Operations overview | Throughput, warehouse readiness, quality, and separated multi-currency revenue |
| `/streaming` | Event streaming | Durable event stream, logical orders, quarantine and replay evidence |
| `/data-sources` | Data sources | REST/CSV/generator operational counts and bounded CSV validation |
| `/pipelines` | Pipeline orchestration | Published Silver/warehouse lineage and execution history |
| `/warehouse` | Warehouse analytics | Published warehouse facts, chronological demand, and separated currency totals |
| `/data-quality` | Data quality | Current serving publication passed; historical incidents remain separated |
| `/monitoring` | System monitoring | Kafka lag, warehouse, quality, ML serving, and pipeline state |
| `/ml` | Demand intelligence | Stored seasonal-naive serving metrics and held-out evaluation rows |
