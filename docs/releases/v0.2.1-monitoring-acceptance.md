## Intentional limitations

- Demonstration data is synthetic and local-only.
- Grafana and Prometheus are loopback operational interfaces.
- Dagster runs as the local orchestration daemon; the current production dashboard profile does not expose a Dagster web UI on port 3002.
- The Monitoring chart shows the latest stored run durations; exact raw milliseconds remain available through chart tooltips and the expanded history table.
